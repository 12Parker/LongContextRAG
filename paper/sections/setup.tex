\section{Experimental Setup}
\label{sec:setup}

\paragraph{Data.}
\textbf{RAMDocs} \citep{wang2025madam} has 500 questions, each with 1--12 documents (5.5 on average) typed
\emph{correct} (supports a gold answer, possibly for a different same-name entity), \emph{misinfo} (supports a wrong
answer) or \emph{noise}. We label a pair a \emph{contradiction} if one side is misinformation and the two answers
differ, \emph{ambiguity} if both are correct with different answers, \emph{consistent} if the answers match, and
\emph{unrelated} if either is noise. A question is a \emph{conflict} question if it has a contradiction pair, and
\emph{clean} otherwise. The released types are imperfect: 163 documents typed \emph{correct} contain a wrong answer,
some as injected misinformation, others incidentally. We leave pairs that touch them out of pair-level metrics, and
questions whose only sign of conflict is such a document (55 of 500; 35 of the confirmatory split) count only in
``All''. Treating them as misinformation is a robustness check.

\textbf{ConflictBank} \citep{su2024conflictbank} builds misinformation differently: for a Wikidata fact, an LLM writes
one evidence passage for the true object and one for a substituted object. We sample 400 questions round-robin over
relations: 300 conflict questions (correct passage, misinformation passage, two distractors from other subjects) and
100 clean ones (correct passage, three distractors). Every question has one gold answer. It had no pilot, so all its
results are confirmatory.

\textbf{WikiContradict} \citep{hou2024wikicontradict} has 253 questions, each with two Wikipedia passages that
genuinely contradict each other; the reference answer is \emph{both} sides. We also run 237 automatically scorable
\textbf{CONFLICTS} \citep{cattan2025conflicts} questions (Appendix~\ref{app:repro}).

\paragraph{Pre-registration and splits.}
We developed the method on a random 200-question pilot split of RAMDocs. Before running anything on the remaining 300
questions (139 conflict, 126 clean, 35 excluded), we committed a pre-registration that fixes the conditions, metrics,
hypotheses and corrections. Every RAMDocs result in the main text is on this confirmatory split; pilot results appear
only in the appendix. Comparisons that were not registered, including every real-detector row of
Table~\ref{tab:main}, are exploratory. After review we registered an addendum (H10, H11 and four re-analyses) and a
second registration (H12--H14), each before running anything it covers; Appendix~\ref{app:repro} lists every
deviation.

\paragraph{Generators and baselines.}
The main generator is \texttt{gpt-4o-mini} \citep{openai2024gpt4o} (temperature 0.1, at most 256 output tokens, seeds
0--2). We replicate the key conditions with \texttt{gpt-4.1} (3 seeds) and with Qwen2.5-7B-Instruct \citep{yang2024qwen25}
(4-bit, local, seed 0), keeping the LLM detector fixed at gpt-4o-mini. We rerun the oracle and LLM-detector
conditions with the minimal skeleton. MADAM-RAG \citep{wang2025madam} is ported unchanged (three debate rounds).
Astute RAG \citep{wang2025astute} and TrustRAG \citep{zhou2025trustrag} use their published prompts and defaults; since
both return one answer, we also run \emph{multi} variants that ask for every valid answer (Appendix~\ref{app:repro}).
We also run the LLM detector on Qwen2.5-7B with gpt-4o-mini generating.

\paragraph{Metrics.}
On RAMDocs an answer is correct if it includes every gold answer and no wrong answer \citep{wang2025madam}. Our primary
metric reads ``includes'' literally: after normalisation, each gold or wrong answer must appear as a whole-word span
of the extracted final answer. A bidirectional variant, which also counts a predicted answer contained in a gold one,
is the robustness metric. We chose the one-way metric before the confirmatory run because it is closer to MADAM-RAG's
published score (Appendix~\ref{app:repro}), and we compare conditions only within our own harness. On WikiContradict
an answer is correct if it contains both sides (bidirectional matching); on ConflictBank we use the RAMDocs metrics.

\paragraph{Statistics.}
We average each question's score over seeds, then report paired differences from the plain format with
cluster-bootstrap 95\% CIs (10,000 resamples) and two-sided sign-flip permutation tests
\citep{efron1993bootstrap,dror2018hitchhiker}. Holm correction \citep{holm1979simple} is applied within each
pre-registered family. A hypothesis is \emph{robustly supported} if it also holds under the robustness metric. One
significance scheme governs the paper: a registered test takes its family's Holm-adjusted $p$, and every other
comparison we report (\nExploratory\ of them) forms one exploratory Holm family. Only results significant under this
scheme are called significant or set in bold. A null difference is not read as equivalence without a TOST
\citep{lakens2017equivalence}. With 139 conflict questions, the minimum detectable effect at 80\% power is
\mdeLo--\mdeHi\ points (median \mdeMed; \citealp{card2020power}).

\paragraph{Cost.}
Token counts come from the API's usage reports. All experiments, pilots included, cost \totalSpend\ in API fees
(prices checked on 2026-10-27; Appendix~\ref{app:repro}); Qwen ran locally.
