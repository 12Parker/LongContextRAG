\section{Experimental Setup}
\label{sec:setup}

\paragraph{Data.}
\textbf{RAMDocs} \citep{wang2025madam} has 500 questions. Each has 1--12 documents (5.5 on average) typed \emph{correct} (supports a gold
answer, possibly for a different same-name entity), \emph{misinfo} (supports a wrong answer) or \emph{noise}. We
label a pair a \emph{contradiction} if one side is misinformation and the two answers differ, \emph{ambiguity} if
both are correct with different answers, \emph{consistent} if the answers match, and \emph{unrelated} if either is
noise. A question is a \emph{conflict} question if it has at least one contradiction pair, and \emph{clean} otherwise.

The released types are imperfect. 163 documents typed \emph{correct} contain a wrong answer; some are injected
misinformation (``Ronald Powell, a renowned chess player''), others mention it incidentally (a navigation menu
listing ``Soccer''). We therefore leave pairs that touch these documents out of pair-level metrics. Questions whose
only sign of conflict is such a document (55 of all 500; 35 of the confirmatory split) belong to neither subset; they
count only in ``All''. Treating every such document as misinformation instead is a robustness check.

\textbf{WikiContradict} \citep{hou2024wikicontradict} has 253 questions, each with two Wikipedia passages that
genuinely contradict each other. The reference answer is \emph{both} sides and no passage is misinformation, so it is
the contrast case to RAMDocs. An answer is scored correct if both of the dataset's answer strings (one per passage)
match a final answer, with the bidirectional matching rule below. \textbf{CONFLICTS} \citep{cattan2025conflicts}: we use the 237 questions that have a
reference answer (outdated-information, misinformation and no-conflict items), which can be scored automatically.

\paragraph{Pre-registration and splits.}
We developed the method on a random 200-question pilot split of RAMDocs. Those pilots motivated directional flags,
removal and document-level placement. Before running anything on the remaining 300 questions (139 conflict, 126
clean, 35 excluded), we committed a pre-registration that fixes the conditions, metrics, hypotheses and corrections.
Every RAMDocs result in the main text is on this confirmatory split. Pilot results appear only in the appendix and are
marked exploratory. Comparisons that were not registered, including every real-detector row of Table~\ref{tab:main},
are exploratory. After a review of a first draft we registered an addendum (H10, H11 and four re-analyses), before
running anything it covers; Appendix~\ref{app:repro} lists every deviation.

\paragraph{Generators.}
The main generator is \texttt{gpt-4o-mini} \citep{openai2024gpt4o} (temperature 0.1, at most 256 output tokens, seeds
0--2). We replicate the key conditions with \texttt{gpt-4.1} (3 seeds) and with the open-weights
Qwen2.5-7B-Instruct \citep{yang2024qwen25} (4-bit, run locally with Ollama, seed 0), keeping the LLM detector fixed at
gpt-4o-mini. Every prompt uses the \emph{default} skeleton, which asks for every valid answer when the passages
support several. To test whether our findings depend on that policy, we rerun the oracle and LLM-detector conditions
with a \emph{minimal} skeleton that drops it (Appendix~\ref{app:prompts}).
MADAM-RAG \citep{wang2025madam} is ported unchanged to the same client: three debate rounds, temperature 0, 128 tokens
per call.

\paragraph{Metrics.}
On RAMDocs an answer is correct if it includes every gold answer and no wrong answer \citep{wang2025madam}. Our primary
metric reads ``includes'' literally: after normalisation (lower-casing; removing punctuation and articles), each gold
or wrong answer must appear as a whole-word span of the extracted final answer. A more lenient bidirectional variant,
which also counts a predicted answer contained in a gold one, is our robustness metric. With the one-way metric,
our port of MADAM-RAG scores 28.5\% on the pilot split and \madamOneWay\% on all 500 questions (published: 28.00, on
an undisclosed subset); with the bidirectional metric it scores \madamBidir\% on all 500. We chose the one-way metric
as primary for this reason, before the confirmatory run; the first draft of the pre-registration had named the
bidirectional one. Because the published subset and scorer are unknown, we do not claim to reproduce the published
number, and we compare conditions only within our own harness. On WikiContradict an answer is correct if it contains both sides;
on CONFLICTS, if it contains the reference answer.

\paragraph{Statistics.}
We average each question's score over the three seeds, then report paired differences from the plain format with
cluster-bootstrap 95\% CIs (10,000 resamples) and two-sided sign-flip permutation tests (10,000 permutations)
\citep{efron1993bootstrap,dror2018hitchhiker}. Holm correction \citep{holm1979simple} is applied within each
pre-registered hypothesis family. A hypothesis is \emph{robustly supported} if it also holds under the robustness
metric. A null difference is not read as equivalence unless a two one-sided test (TOST; \citealp{lakens2017equivalence})
with a pre-set margin confirms it. With 139 conflict questions, the smallest effect our comparisons detect with 80\% power is \mdeLo--\mdeHi\ points
(median \mdeMed; \citealp{card2020power}); smaller differences may go unseen.

\paragraph{Cost.}
Token counts come from the API's usage reports. Prices were checked on 2026-10-27 (gpt-4o-mini: \$0.15, \$0.075
cached, and \$0.60 per million input, cached-input and output tokens; gpt-4.1: \$2.00, \$0.50 and \$8.00). All experiments in
this paper, pilots included, cost \totalSpend\ in API fees; Qwen ran locally.
