\section{Experimental Setup}
\label{sec:setup}

\paragraph{Data.}
\textbf{RAMDocs} \citep{wang2025madam} has 500 questions, each with 1--12 documents (5.5 on average) typed
\emph{correct} (supports a gold answer, possibly for a different same-name entity), \emph{misinfo} (supports a wrong
answer) or \emph{noise}. A pair is a \emph{contradiction} if one side is misinformation and the answers differ,
\emph{ambiguity} if both are correct with different answers, \emph{consistent} if the answers match, and
\emph{unrelated} if either is noise. A question is a \emph{conflict} question if it has a contradiction pair, and
\emph{clean} otherwise. Some documents typed \emph{correct} contain a wrong answer; questions whose only sign of
conflict is such a document count only in ``All'' (Appendix~\ref{app:repro}).

\textbf{ConflictBank} \citep{su2024conflictbank}: for a Wikidata fact, an LLM writes one evidence passage for the true
object and one for a substituted object. We sample 400 questions round-robin over relations: 300 conflict questions
(correct passage, misinformation passage, two distractors from other subjects) and 100 clean ones (correct passage,
three distractors). Every question has one gold answer. It had no pilot, so all its results are confirmatory. A
\emph{majority} variant gives each conflict question the correct passage and ConflictBank's three wrong-object
passages for that fact (its misinformation, temporal and semantic conflicts, all supporting the substituted object,
which we count as misinformation), so the false side outnumbers the truth three to one.

\textbf{RAGuard} \citep{zeng2025raguard} pairs PolitiFact claims (true or false) with Reddit posts that an LLM
labelled supporting, misleading or unrelated, so the misleading side is real online text. We keep 294 claims with at
least one supporting and one misleading post (up to two of each, plus two unrelated posts) and 100 claims with no
misleading post; the question is whether the claim is true. Its labels are LLM-assigned stances, not verified facts.

\textbf{WikiContradict} \citep{hou2024wikicontradict} has 253 questions, each with two genuinely contradicting
Wikipedia passages; the reference answer is \emph{both} sides. We also run 237 automatically scorable
\textbf{CONFLICTS} \citep{cattan2025conflicts} questions (Appendix~\ref{app:repro}).

\paragraph{Pre-registration and splits.}
We developed the method on a random 200-question pilot split of RAMDocs. Before running anything on the remaining 300
questions (139 conflict, 126 clean, 35 excluded), we committed a pre-registration that fixes the conditions, metrics,
hypotheses and corrections. Every RAMDocs result in the main text is on this confirmatory split; pilot results appear
only in the appendix. Comparisons that were not registered, including every real-detector row of
Table~\ref{tab:main}, are exploratory. Eight addenda (H10--H31 and several re-analyses) were each committed before running anything
they cover, so these hypotheses were formed after the original confirmatory results were known; the confirmatory core
registered before any data is H1--H9. Re-analyses registered in the last two addenda use data we had already seen, and
are reported as such (Table~\ref{tab:claims}). The repository's commit history is the only timestamp. Appendix~\ref{app:repro} lists every deviation.

\paragraph{Generators and baselines.}
The main generator is \texttt{gpt-4o-mini} \citep{openai2024gpt4o} (temperature 0.1, at most 256 output tokens, seeds
0--2). We replicate key conditions with \texttt{gpt-4.1}, Qwen2.5-7B-Instruct \citep{yang2024qwen25} (4-bit, local),
two current reasoning models, \texttt{gpt-6-luna} (3 seeds) and \texttt{gpt-6.1-terra} (seed 0), and Anthropic's
Claude Haiku 5.5 (3 seeds) and Claude Sonnet 5.5 (seed 0). The reasoning and Claude models run at their default
temperature with up to 4,096 output tokens, since they reason before answering. The LLM detector is gpt-4o-mini
except in the crossed design (H24), where six detectors and six generators form \hTwentyFourCells\ pairs on ConflictBank. On ConflictBank the primary prompt is the single skeleton; the default and
minimal skeletons are robustness checks. We rerun the oracle and LLM-detector conditions with the minimal skeleton.
MADAM-RAG \citep{wang2025madam} is ported unchanged (three debate rounds). Astute RAG \citep{wang2025astute} and
TrustRAG \citep{zhou2025trustrag} use their published prompts and defaults; since both return one answer, we also run
\emph{multi} variants that ask for every valid answer (Appendix~\ref{app:repro}). We also run the LLM detector on
Qwen2.5-7B with gpt-4o-mini generating. A detector pipeline counts as one detector call plus one generator call. Two
controls test whether a crossed cell's gain is only a stronger model's answer (H27): the generator given the detector
model's own plain answer as a hint, and the detector model used as the generator. An artefact probe (H29) reruns two
detectors on ConflictBank with the passage order reversed and with every passage paraphrased by one model.

\paragraph{Metrics.}
On RAMDocs an answer is correct if it includes every gold answer and no wrong answer \citep{wang2025madam}. Our primary
metric reads ``includes'' literally: after normalisation, each gold or wrong answer must appear as a whole-word span
of the extracted final answer. A bidirectional variant, which also counts a predicted answer contained in a gold one,
is the robustness metric. We chose the one-way metric before the confirmatory run because it is closer to MADAM-RAG's
published score (Appendix~\ref{app:repro}), and we compare conditions only within our own harness. On WikiContradict
an answer is correct if it contains both sides (bidirectional matching); on ConflictBank and RAGuard we use the RAMDocs metrics. We also report
the share of answers that contain the misinformation, the share that abstain (``unknown''), and accuracy among answered
questions. An LLM judge (gpt-6.1-terra) agrees with the primary metric on \judgeAgree\% of \judgeN\ stratified
conflict-question outputs ($\kappa=\judgeKappa$); the metric is slightly conservative, missing some paraphrases. A
200-output sheet for a human audit is released, but it has not been labelled.

\paragraph{Statistics.}
We average each question's score over seeds and report paired differences from the plain format with
bootstrap 95\% CIs that resample questions (10,000 resamples) and two-sided sign-flip permutation tests
\citep{efron1993bootstrap,dror2018hitchhiker} (10,000 permutations, extended to 200,000 when none reaches the
observed statistic, so that a $p$-value can survive a large Holm family). CIs are unadjusted; significance is decided by the adjusted $p$
below, so an interval can exclude zero for a difference that is not significant. A hypothesis is \emph{robustly supported} if it also holds under the
robustness metric. A registered test takes its family's Holm-adjusted $p$ \citep{holm1979simple}; the exploratory
comparisons of the condition tables (\nExploratory\ of them) form one Holm family; the later re-analyses (the grid,
utility, H27--H31) use the families stated with them. Only results significant under these corrections are called
significant or set in bold. A null difference is not
read as equivalence without a TOST \citep{lakens2017equivalence} at $\pm$3 points. Selective accuracy is a ratio
(correct over answered, pooled over questions and seeds), tested by swapping conditions within questions. Pooled
estimates use a multilevel model with random effects for generator, benchmark and setting.
Appendix~\ref{app:repro} gives the minimum detectable effect.

\paragraph{Cost.}
Token counts come from the API's usage reports. All experiments, pilots included, cost \totalSpend\ in API fees
(prices checked on 2026-10-27; Appendix~\ref{app:repro}); Qwen ran locally.
