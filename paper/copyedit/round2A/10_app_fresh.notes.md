## Issues for the authors
1. **Sign mismatch between magnitude and interval (H38).** "so it understates the flag's advantage by \ajdThirtyShift\ \jdThirtyShiftCI\ and \ajdTwentyThreeShift\ \jdTwentyThreeShiftCI\ points." The point values are absolute (1.2, 2.6) but the intervals are signed and negative ([−1.9, −0.6], [−3.9, −1.4]). A reader sees "by 1.2 [−1.9, −0.6]". Use absolute-valued CI macros, or report the signed shift (matcher minus judge) with "changes".
2. **"and both for \hcLabBoth\%"** — "both" is ambiguous: both pages support their labelled answer (i.e., the conjunction of the two previous findings), or a page supports both answers? One word ("both labels hold") would fix it, but I could not tell which is meant.
3. **"The judge audit of the labels (\hcLabN\ items)"** — does not say which judge. Elsewhere the appendix uses "the \S17.3 judge"; if it is the same one, say so (needs a digit, so not added).
4. **"Long, noisy pages leave many stances unclear to it, so the dataset's oracle ... is a label transfer."** The causal "so" reads oddly: the oracle is a label transfer because the labels are used as released and not verified, not because the judge finds stances unclear. Consider "and" or rewording; I kept the logic as written.
5. **"the analysis reproduces them exactly (maximum drift \frDrift\ points)"** — \frDrift = 0.00, so consistent; fine, noting only that "exactly" depends on that macro staying 0.00.
6. **Slope CI \frSlopeCI\ = [0.77, 1.00] "includes 1"** — 1 sits on the upper bound; true as written, but a reviewer may question it given rounding. Consider an extra decimal.
7. **"(gpt-4o-mini generator \frSelMiniObs\ points against \frMiniDetMiniObs\ with the gpt-4o-mini detector ...)"** — \frSelMiniObs = +12.0 and \frMiniDetMiniObs = +7.7, but Table~\ref{tab:fresh} (generated) shows +16.0 (Claude Haiku detector) and +11.4 (gpt-4o-mini detector) for the gpt-4o-mini generator; likewise gpt-6.1-terra +5.3 / −3.5 vs the table's +7.0 / −4.0. The selection numbers match the 300 conflict + 100 clean mix (16.0×0.75 + 0×0.25 = 12.0; 11.4×0.75 − 3.7×0.25 ≈ 7.7), so they are all-question effects while the table reports conflict and clean separately; the text should say "over all questions" (no room without adding words).
8. **Table~\ref{tab:hc} caption (generated):** the LLM-directional observed effect for gpt-6-luna is −8.6 [−14.9, −2.8], a significant harm (unadjusted). The text's "the observed effects are smaller" is accurate (smaller than predicted) but does not mention that one is a clear harm; results.tex mentions it only via "\hcLlmPredLuna\ vs \hcLlmLuna". Fine to leave; flagging in case a reviewer reads "smaller" as "negligible".
